# 0009 附件对象存储使用 MinIO .NET SDK

状态：已采纳
日期：2026-10-20
关联：T-013

## 背景

设计书要求附件可存本地文件或 MinIO / S3 兼容对象存储，并能生成短时下载地址。数据库只保存元数据，存储实现需隔在统一接口后。本机已有 Minio 7.0.0 和其 .NET 8 依赖；该稳定版于 2025-11-05 发布，满足依赖发布时间要求。

## 决定

基础设施层使用 Minio 7.0.0 实现 S3 兼容存储，版本集中写在 `backend/Directory.Packages.props`。应用层只依赖 `IFileStorage`，按配置选择本地或对象存储。对象存储的地址、桶、访问密钥只从部署配置读取，不提交实际值。能从浏览器访问对象存储时，先完成审批单查看权限检查，再生成几分钟有效的预签名地址；否则由服务端读取并转发。

## 备选方案

直接手写 S3 签名会扩大安全敏感代码面；引入 AWS SDK for S3 也可行，但当前未在本机缓存且设计的主要目标是 MinIO 兼容部署。Minio SDK 已缓存、可离线还原，故选用它。

## 影响

基础设施层新增第三方依赖及配置。真实 MinIO 检查只在显式配置 `APPROVAL_TEST_MINIO` 时运行；默认检查覆盖本地存储、权限和清理，不依赖外部服务。切换存储配置不会自动搬运旧文件，需运行单独的迁移命令。
