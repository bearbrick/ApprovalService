# 0010 组织 Excel 导入导出使用 MiniExcel

状态：已采纳（2026-10-20 用户同意）
日期：2026-10-20
关联：T-007

## 背景

组织初始化要导入部门、人员和上下级；业务管理员还需下载同格式模板。CSV 可以先满足不依赖包的批量录入，但设计书要求 Excel 导入。Excel 文件必须先解析成同一组织批次，再执行工号重复、缺失引用和环路的完整校验，不能在解析时直接写数据库。

## 决定

在基础设施层引用本机已缓存的 `MiniExcel` 1.33.0（NuGet 包约 373 KB，Apache-2.0，项目源为 `mini-software/MiniExcel`）；它同时支持 `.xlsx` 读写，当前目标框架下没有外部传递依赖。Excel 与 CSV 都转换成 `OrganizationImportBatch`，经领域层同一校验和应用层同一提交路径。导入限制文件大小与行数，拒绝未知列和不支持的文件；模板导出只写列名和说明，不包含任何真实人员数据。用户已明确同意引入该缓存包。

## 备选方案

本机缓存的 NPOI 2.7.6 包体约 13 MB，接口和传递依赖更多；ExcelDataReader 3.6.0 只读，不能导出模板。只保留 CSV 不满足既定 Excel 验收标准。

## 影响

仅基础设施层增加 MiniExcel 依赖；领域规则和契约不依赖该库。后续 Excel 模板列变化须与 CSV、开放接口字段和导入检查同步，并继续按每个批次一次收集全部问题的规则处理。
