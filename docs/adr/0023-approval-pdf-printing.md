# 0023 审批单使用 PDFsharp 与 ZXing.Net 生成可归档 PDF

状态：已采纳（2026-10-26 用户明确同意本机缓存依赖）
日期：2026-10-26
关联：T-015

## 背景

打印必须包含中文、跨页明细、手写签名与四图票据页，不能随产品分发系统字体。现有中心已经提供按人员、嵌入应用和字段权限裁剪的详情，打印应复用这条授权路径。

## 决定

基础设施层引入缓存 PDFsharp 6.2.4（MIT，4.4 MiB）与 ZXing.Net 0.16.11（Apache-2.0，10 MiB），来源为 NuGet.org 的本机缓存，不下载新包。PDFsharp 手工实现有界换行、分页与重复表头，二维码使用 ZXing.Net。字体由本地组织管理员上传有授权的 TrueType 字体，生成文档时嵌入字体子集；字体不得进入仓库或发布包。只允许已认证人员下载其可见审批单 PDF，字段可见性与中心详情一致。

## 备选方案

MigraDoc 未缓存，当前不新增下载；QuestPDF 的商业许可限制不适合默认分发。浏览器打印不能满足服务端 PDF 归档接口。

## 影响

PDF 渲染置于基础设施层，经应用层扩展接口调用；纯引擎不引用 PDF 库。打印计数与操作记录须按同一审批单并发版本原子提交；失败生成不记成功打印。字号、纸张方向、跨页与中文嵌入需自动检查和人工截图验收。

2026-10-26 补充确认：用户明确同意同一打印路径支持来源应用 API Key 归档自己的审批单；人员 JWT 维持中心权限，应用归档审计明确记录应用编码。
