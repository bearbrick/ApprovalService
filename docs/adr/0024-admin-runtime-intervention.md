# ADR 0024：管理员运行干预使用本地 JWT 和原子权限复核

状态：已采纳（2026-10-26 用户在集成任务确认）
日期：2026-10-26

## 背景

引擎已有改派、跳转、终止命令，但没有管理页面可调用的真实协议。业务 API Key 终止接口和人员委托接口不代表管理员运行干预。

## 决定

使用独立的本地 JWT 管理查询和命令接口。管理权复用 FlowManagementAccessRules：在职组织管理员可管理全部流程；具有 flow-admin 角色的人员仅能管理直接所属部门流程。Flow.AdministratorId 不单独授予管理权限。保密审批单还必须具备当前中心认可的实际参与关系，管理员角色不能越过保密边界；查询不返回业务字段或完整执行图。

首个切片支持当前任务改派、人工节点跳转和终止。命令必须带原因、稳定 X-Request-Id 及详情读取时的 expectedVersion。服务端从 JWT 取得实际操作者，经统一运行时和引擎入口执行；运行时拒绝过期修订，最终数据库事务重新核对管理权限、保密参与关系与接手人在职状态，同事务保存状态、任务、原因审计及待发项。未知结果重试复用同一请求 ID；引擎按实例状态保存已处理请求标识，人员命名空间隔离不同管理员请求。

固定审批人维护只修改草稿，再由管理员明确发布新版本。历史发布版本不可变，在途实例继续使用发起时的旧发布版本。当前任务改派只改所选实例的运行状态，不改任何流程定义。

## 后果与范围

不新增依赖或数据库结构。最近列表最多返回一百条已授权在途记录，额外记录按实例 ID 定位。跳转限于锁定版本中的人工节点，取消原全部待办与分支后重新推进。查询详情允许读取已结束单据，以便确认终止结果和授权幂等重放；新终止由引擎拒绝非在途状态。

批量离职交接、批量草稿人员替换、未来节点改派与网关/自动节点跳转留待后续用例，不展示假提交入口。外置 Chrome 视觉验收由集成任务执行。
