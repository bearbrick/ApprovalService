# 管理后台原型覆盖清单

依据：设计书 V0.7 §3、§4、§6、§8、§9、§10、§11、§12，以及接口契约与 ADR 0002、0006。所有入口以 `admin.html` 为基础，后接下表 hash。

| 设计内容 | 入口 | 可评审的页面与交互 | 模拟边界 |
| --- | --- | --- | --- |
| 管理工作台、异常关注 | `#overview/` | 运行概况、超时待办、失败回调、离职交接、处理量与最近操作；可进入对应管理页 | 概况和统计使用虚构固定样例，回调待处理数随演示操作更新；不采集真实运行状态 |
| 流程管理、版本发布后的不可修改性 | `#flows/list` | 搜索及状态筛选、新建、JSON 示例导入、停启用及原因、版本列表、复制为草稿、进入设计器 | 停启用和草稿保存在浏览器；不编译执行图，不校验正式流程 JSON，不解析 BPMN 文件；版本列表为演示 |
| 流程模板库 | `#flows/templates` | 费用、采购、请假、加班、出差、付款、用印、合同、物品领用、质量异常十类模板；复制后生成草稿 | 不产生业务单据；模板内容为界面样例，尚非完整可执行定义 |
| 部门、人员、多部门、岗位职级、上下级、在职状态 | `#org/people` | 部门树、姓名工号搜索、人员新增与编辑、部门负责人和分管领导设置、导入预检 | 本地数据维护；工号唯一性会校验；导入预检使用预置问题和记录，不读取真实 Excel；不执行完整组织环路检测 |
| 账号开通、禁用、初次改密、作废登录令牌 | `#org/people` | 人员账号弹窗、操作原因、开通与禁用状态、登录令牌作废和改密操作记录 | 不操作真实密码和令牌；没有真实权限体系 |
| 每应用的用户与部门绑定、可信来源 | `#org/bindings` | 绑定清单、调整与新增绑定、按工号自动匹配预览；说明可信来源不被外部覆盖 | 自动匹配与绑定使用固定样例，不调用组织推送接口 |
| 角色、管理权限和数据范围 | `#org/roles` | 角色新增、成员、权限复选项、全部／授权流程／本部门及下级／本人范围 | 保存本地配置，不实际拦截请求或切换真实数据权限 |
| 审批矩阵 | `#org/matrix` | 部门、金额区间、物料类型、审批人规则列表，新增与编辑 | 展示管理方式；不执行金额区间解析、重叠检测或审批人解析 |
| 工作日时限、节假日、调休 | `#org/calendar` | 十月日历、点击日期维护说明与类型、工作时间配置 | 日历记录保存在本地；不计算正式截止时间，所示假期仅为演示 |
| 离职交接与留痕 | `#overview/` | 郑涛离职演示、选择接收人、填写原因、追加操作日志 | 只演示交接确认和日志，不真实迁移待办与流程中指定人员；郑涛离职是演示场景，并非设计书组织事实 |
| 应用注册、授权、回调、API Key、签名密钥 | `#apps/list` | 应用列表、三步接入向导、流程授权、回调、嵌入来源、统一待办范围、停用、密钥轮换确认 | 密钥使用明确的 DEMO 文本，不能用于鉴权；不发送网络请求，不生成真实密钥 |
| 接入验证与回调测试 | `#apps/list` | 本地模拟测试响应、事件信息、验签结果演示、操作日志 | 不实际验签、传输或改变业务单据 |
| 接口调试、错误反馈、短时嵌入令牌 | `#apps/debug` | 可编辑 JSON、接口选择、正常／参数错误／未授权／冲突响应；非法 JSON 显示错误；嵌入令牌示例 300 秒 | 纯沙箱，不调用接口；接口形态为设计示意，以正式契约为准 |

| 管理员干预、原因必填、只读业务快照 | `#runtime/` | 搜索状态筛选；更换当前审批人、跳转、终止、重发提醒、重发回调；原因必填并追加日志；明细导出 | 状态与人员为本地变化；不执行引擎。异常待处理作为节点提示，不增加暂停状态；后续节点审批人修改仅由配置意图表达 |
| 统一出站、至少一次投递、重试、请求记录 | `#outbound/queue` | 回调队列与状态筛选、次数、下一次重试、请求记录、单项或全部重试 | 重试直接模拟成功；不实际请求、计时或实现幂等；说明保留 eventId、接收方去重 |
| 发起前／同意前校验、取人、自动业务动作 | `#outbound/hooks` | 钩子类型、超时与失败策略、接口地址配置、模拟测试 | 不调用业务接口；不执行事务或外部动作 |

| 节点瓶颈、超时率 | `#reports/node` | 数值条形图、可访问文本、平均与 P90 耗时、超时率、处理量、导出 | 节点样例固定，顶部筛选不重算节点明细 |
| 人员／部门积压与处理效率 | `#reports/people` | 人员、部门、积压、平均时长、超时次数和处理量、导出 | 人员样例固定，顶部筛选不重算人员明细；管理范围说明不等于真实权限校验 |
| 站内／邮件渠道、到期与汇总提醒 | `#system/notifications` | 邮件服务器、汇总时间、提醒偏好、保存、测试邮件对话框与日志 | 不连接 SMTP；初版超时只提醒，不自动同意或拒绝；企业微信、钉钉仅标为后续扩展 |
| 附件本地／MinIO／S3、迁移、大小与权限 | `#system/storage` | 20 MB 默认上限、存储配置、模拟连接检测、迁移预览、备份与权限说明 | 不读取真实数据库、附件或存储连接；迁移仅演示任务完成 |
| 单位上传授权字体、打印字体默认项 | `#system/storage` | 字体列表、TTF／OTF 选择、授权确认、默认字体设置 | 仅保存文件名称，不读取、上传、嵌入字体，不打包系统字体 |
| 本地账号、访问令牌、平台扩展预留 | `#system/security` | 本地账号与嵌入令牌、访问令牌 30 分钟设置、可信来源、OIDC／ESB 预留项 | 预留选项禁用，不宣称平台功能已实现；30 分钟指访问令牌，不是嵌入令牌 |
| 操作日志与审计 | `#system/logs` | 操作人与对象搜索、管理动作追加、导出 | 演示操作只追加到浏览器列表；不实现防篡改链、服务端审计和链路追踪 |

## 共用交互与数据边界

- 界面复用标签服务的深蓝顶栏、浅色侧栏、控件尺寸、表格密度、品牌图片和图标；不引入外部依赖。
- 本地状态保存在浏览器 `localStorage`；清除相应缓存后恢复虚构样例。审批、组织、接口与统计均不代表生产实现。
- 初始流程与其他原型页统一：`EXPENSE` v3、`PURCHASE_REQUEST` v2 钉钉式、`CONTRACT_REVIEW` v1、`QUALITY_EXCEPTION` 自由画布。
- 使用设计书中的演示人员，并保留当前模块自己的本地状态。跨页跳转不保证携带同一记录，也不对其他原型页同步数据。
- 管理后台不产生业务单据，不提供业务表单修改；业务系统通过数据接口发起、撤回、重新提交。
