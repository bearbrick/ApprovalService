# 常用审核场景评审清单

本清单用于核对原型和后续实现，不能把配置入口等同于引擎已经执行该规则。原型只保留自由画布，所有业务单据由业务系统发起。

| 场景 | 流程 / 规则入口 | 评审重点 | 正式实现要验证的边界 |
| --- | --- | --- | --- |
| 普通报销 | 费用报销画布 | 连续上级、金额分支、财务或签、出纳办理、抄送 | 相邻同一人去重；金额刚好等于阈值 |
| 大额报销 | 费用报销金额连线 | 超额走管理层，其他情况有明确兜底 | 多条条件同时成立时按优先级选一路 |
| 采购联合评审 | 采购画布 | 金额会签、专业评审并行汇合、合同子流程、自动业务动作 | 分支不同时间完成、拒绝取消其他任务、子流程失败 |
| 合同会审 | 合同画布 | 法务和财务分别审批，汇合后终审 | 尚有分支未完成时不可提前终审 |
| 质量返工 | 质量画布 | 质检判断、生产返工后重新质检、合格后并行放行 | 再次进入节点重新计算处理人；避免无限循环 |
| 按职责找人 | 节点审批人来源；管理后台组织与矩阵 | 14 种来源、角色部门限制、层级、矩阵、业务取人 | 多部门身份、矩阵未命中、取人接口失败 |
| 票签 / 会签 / 或签 | 节点多人审批方式 | 比例、权重、拒绝策略、余下任务处理 | 重复点击不重复计票，已不可能通过时及时拒绝 |
| 人员异常 | 流程规则人员策略 | 无人、自审、重复、离职或停用 | 发起预览和到达节点组织变化；兜底人员也不可用 |
| 退回修改 | 流程规则退回重提；审批中心更多操作 | 发起人 / 前序节点，重提从头或回原节点 | 并行只允许本分支或分叉之前，旧待办正确取消 |
| 补充材料 | 审批中心要求补充；示例业务 | 回业务系统补资料，返回当前处理人 | 补充期间审批操作限制、快照版本和留痕 |
| 临时协作 | 节点操作权限；审批中心更多操作 | 前 / 后 / 并行加签、未处理减签、征询、转交 | 谁可移除谁、重复转交、征询不推进主流程 |
| 休假与离职 | 个人委托；管理后台交接 | 时间范围、流程范围、存量待办、代理留痕 | 不连环委托；原处理人与代理人并发只能处理一次 |
| 处理时限 | 流程规则提醒；工作日历 | 工作日到期、提前提醒、超时提醒、汇总 | 节假日调休，重复提醒节流；初版超时不自动审批 |
| 保密与审计 | 流程查看范围；节点字段权限 | 只读业务快照、审批填写字段、意见签名、操作原因 | 隐藏字段与附件实际鉴权、管理员干预必须留痕 |
| 外部系统失败 | 钩子配置；管理后台出站队列 | 原因可见、重试、管理员介入、回调事件去重 | 不在事务中等待网络；重试不重复生成业务单据 |
| 发布与在途版本 | 版本页签 | 草稿和已发布版本区分、发布检查、说明与历史 | 已发布不可修改；在途实例继续使用发起时版本 |

## 原型与正式实现的分界

- 原型画布检查用于发现明显的结构或配置缺失；完整语义校验、事务、幂等和权限由正式引擎与服务端验证。
- 路径演示只覆盖可识别的比较条件和有限图遍历；复杂条件及返工再提交需要明确暂停提示，不展示虚假的“审批通过”。
- 管理干预、委托、审批处理及回调使用各模块的本地演示状态；当前不是跨模块生产联调。
- 企业微信 / 钉钉渠道、统一登录、超时自动同意 / 转交仍为后续扩展；电子签章不在当前范围。
