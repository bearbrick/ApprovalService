# 审批中心与手机原型覆盖

对应设计书 §4、§6、§7。所有记录均为虚构示例；桌面和手机共用浏览器本地状态，不调用真实审批接口。

## 桌面审批中心

入口：[审批中心](center.html)。演示财务处理人为赵敏、部门负责人为李娜、出纳为刘洋。

| 功能 | 页面入口与交互 |
| --- | --- |
| 待办、已办、抄送、我发起的 | 四个页签，数量随操作更新；我发起的只查看进度和催办 |
| 搜索、筛选、加急、未读 | 标题/编号/摘要搜索，流程、时间、状态筛选；加急样例排在首位，未读标题加粗 |
| 批量同意 | 待办表格勾选后打开确认弹窗，填写统一意见并更新列表 |
| 业务数据 | 打开详情查看只读业务快照、摘要、报销/采购明细与合计 |
| 业务原单 | 详情页签「查看业务原单」链接至示例业务页，不在审批中心编辑业务单据 |
| 审批进度 | 右侧时间线和「流程进度」页签显示当前节点与处理人 |
| 操作审计 | 「操作记录」页签追加操作、意见、对象与时间 |
| 同意、拒绝、退回 | 底部操作栏；拒绝和退回要求原因；更新状态与列表分类 |
| 转交、加签、减签 | 「更多操作」弹窗；选择人员，加签方式入口，减签校验本人已加签人员 |
| 征询、补充、抄送 | 「更多操作」弹窗；要求补充进入待补充状态并移入已办 |
| 撤销同意 | 自己已同意且演示中下一步尚未处理的审批，底部显示入口，返回待办 |
| 评论、@、附件入口 | 「评论与沟通」页签可发表并保存文字、@ 人员；选择附件显示演示反馈 |
| 意见暂存与常用语 | 详情输入时自动保存在本地；点击常用语快速填写 |
| 附件预览 | 详情附件卡片展示演示电子发票/图片预览 |
| 打印审批单 | 详情右上角，含明细、合计、意见、签名、页眉页脚、打印次数、水印和演示二维码占位 |
| 个人签名 | 「个人设置」可手写或上传图片，保存到本地并供打印展示 |
| 委托 | 「个人设置」选择代理人、开始结束时间、流程范围及现有待办选项；验证日期先后 |
| 消息与偏好 | 顶部消息弹窗可打开对应审批；个人设置维护消息偏好 |
| 催办 | 「我发起的」详情底部催办，模拟一小时限流 |

## 手机审批

入口：[手机审批](mobile.html)，独立手机布局，可直接在手机宽度下访问。桌面宽度显示居中的手机预览壳。

| 功能 | 页面入口与交互 |
| --- | --- |
| 四个底部页签 | 待办、已办、抄送、我的；待办数量随操作更新 |
| 搜索、流程筛选 | 卡片列表搜索和流程筛选；右上刷新、列表下拉刷新 |
| 摘要卡片 | 流程、发起人、部门、金额、加急、状态、当前节点和业务单号 |
| 详情 | 只读业务数据、明细、金额、附件和时间线 |
| 固定操作栏 | 同意、拒绝及更多操作固定在底部，操作后更新共享状态 |
| 更多操作 | 退回、转交、加签、征询、要求补充、抄送与暂存入口 |
| 意见草稿 | 输入时自动暂存，与桌面同一审批单的草稿共享 |
| 拍照与签名 | 原生文件选择器/相机入口；图片压缩后保存至本地；触屏手写签名 |
| 评论与 @ | 详情底部评论入口，保存评论文本并提供 @ 发起人快捷入口 |
| 个人设置 | 我的页面维护委托、签名、常用语和消息偏好；展示我发起的审批 |
| 登录演示 | 默认进入已登录体验；我的 → 退出登录后显示登录页；任意非空演示工号密码可登录，不保存密码 |

## 模拟边界

- 本原型不实现生产鉴权、接口、审批引擎、并发锁、事务、组织权限、附件访问控制、真实通知、回调或委托派单；状态只保存在本浏览器 `localStorage`。
- 下一步尚未处理、允许的退回目标和加减签对象为固定演示状态，未计算真实执行图。流程上的禁用操作、批量许可、钩子校验和票签规则由后续生产实现执行。
- 委托的日期和人员有保存反馈，范围和现有待办选项用于评审表单；不会运行后台调度。消息勾选有本地保存反馈，不实际发送邮件或站内通知。
- 打印是 HTML 凭证预览，使用浏览器「打印 / 另存为 PDF」；未接入服务端 PDF 生成、分页引擎、字体管理或真实二维码。二维码明确标为演示占位，不可扫描跳转。
- 附件预览是绘制的示例票据，不代表真实 PDF 或图片解码；手机拍照仅压缩并保存到本地，桌面评论附件仅提供文件选择与提示，未上传服务器。
- 签名用于界面评审，本地图片不具有电子签章或法律身份验证能力。
- 不在审批中心发起、撤回、重新提交或修改业务单据；业务原单入口跳转到原型示例业务页。
