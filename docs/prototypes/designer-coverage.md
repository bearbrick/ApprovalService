# 流程设计原型覆盖说明

关联任务：T-024。设计依据为设计书第 3、4、5、7 节；本文件只说明原型已实现的交互，不变更产品设计或接口契约。

## 入口与样例

| 入口 | 样例内容 | 保存范围 |
| --- | --- | --- |
| `designer.html#purchase`（默认） | 采购申请 V2；部门审批、金额条件、总经理与财务总监会签、采购执行和抄送 | 独立的采购草稿 |
| `designer.html#expense` | 费用报销 V3；连续上级、相邻去重提示、金额分支、财务或签、出纳付款 | 独立的报销草稿 |
| `designer.html#contract` | 合同评审 V1；资料核对、法务与财务并行评审、终审、通知父流程 | 独立的合同草稿 |
| `designer.html#quality` | 质量异常 V1；质检确认、排他判断、生产返工回路、并行分叉、质量与生产经理审批、并行汇合、归档 | 独立的质量草稿 |

四个路由切换完整节点、字段、版本与预览内容。未保存修改在本页路由切换时保留在内存；“保存草稿”按流程分别写入浏览器 localStorage。人员、金额、记录均为虚构样例。

## 第 3 节：流程设计器

| 设计项 | 页面 / 控件 | 精确交互范围 |
| --- | --- | --- |
| 钉钉式树形 | 流程设计 | 节点可选择，右侧属性随选择更新；金额条件可编辑，默认兜底分支可查看；新增节点插入结束之前 |
| 自由画布 | 质量异常；或“转为自由画布” | 节点可拖动，已有连线可点击编辑，可新增连线及条件文字；支持编辑回到此前节点的连线 |
| 单向转换 | 采购 / 报销的“转为自由画布” | 确认后保留草稿数据，切换为画布；不提供反向转换 |
| 审批、办理、抄送 | 添加节点 / 节点设置 | 可新增、命名、设置来源与处理人；抄送支持“要求已阅”配置 |
| 排他、包容、并行 | 添加节点；合同并行样例 | 新增分支在树形显示两条可编辑路线，可改名称、处理人和条件；并行不显示条件；质量画布将排他判断与并行分叉、汇合分开表示 |
| 子流程 | 添加节点 → 子流程 | 可设置目标流程、是否等待及文本形式的字段映射 |
| 自动节点 | 添加节点 → 自动节点 | 可设置业务动作名称及重试间隔说明；失败转管理员以说明呈现 |
| 节点删除 | 节点设置底部 | 可删除新增节点；为保证示例主路径完整，基础节点只允许改配置，不允许删除 |
| 导入、导出 | 工具栏 | 导出本原型的 `.prototype.json`，可恢复节点、字段和设置；导入检查原型标识及版本，拒绝不兼容文件 |
| 发布与历史 | 顶部发布；版本管理 | 检查名称、处理人、字段完整性、重复 key、条件所需金额字段；必填发布说明；本地版本递增并追加历史、配置数量摘要 |
| 提交前预览 | 流程预览 | 采购和报销可输入金额，按阈值重新计算是否经过管理层；合同与质量显示其样例路径，质量提示返工与并行语义 |
| 测试模式 | 顶部测试模式 | 按当前样例节点逐步推进，展示当前 / 已完成状态，可模拟拒绝终态；不创建审批单 |

导入导出只演示原型草稿搬运，不生成正式流程 JSON 或 BPMN 2.0 文件。执行图编译、可达性、网关配对、表达式解析、任意复杂路径模拟由正式功能实现；当前发布检查不会声称已经完成这些校验。

## 第 4 节：中国式审批规则

| 设计项 | 页面 / 控件 | 精确交互范围 |
| --- | --- | --- |
| 14 种找人来源 | 选中审批节点 → 审批人来源 | 指定成员、角色、岗位 / 职级、直属上级、连续多级上级、部门负责人、业务数据部门、分管领导、业务数据人员、审批矩阵、业务系统接口、上一步指定、发起人自选、发起人本人均可选；切换显示来源说明并清空原配置 |
| 来源参数 | 来源下方配置输入 | 可输入成员、角色、层级、字段 key、矩阵或接口名称等；不查询真实组织、不调用取人接口 |
| 四种多人审批 | 节点 → 多人审批方式 | 依次、会签、或签、票签可切换，解释对应规则；票签显示比例和人员权重输入 |
| 无人、自审、重复、离职 | 流程规则 → 自动处理 | 对应默认策略与备选项可选择并保存 |
| 动态计算审批人 | 自动处理说明；预览说明 | 说明到达节点按最新组织关系计算，预览结果可能不同；不模拟组织变更 |
| 会签拒绝 | 流程规则 → 退回、撤回与重新提交 | 立即结束或等待所有人两种策略可选 |
| 退回、转交、加减签、征询、要求补充、抄送、撤销同意、评论与 @、暂存、批量同意 | 节点 → 操作权限 | 11 项开关控制本地节点配置；实际处理动作在审批中心原型展示 |
| 退回位置和重提路径 | 流程规则 | 退回目标范围与从头 / 回节点可选；并行限制及要求补充后的返回位置有说明 |
| 发起人操作、加急、代发、自选、催办、撤销 | 业务示例及审批中心 | 设计器只配置撤回范围和选人来源，不在审批中心增加业务单据发起或业务数据修改 |
| 意见与签名 | 节点 → 意见与字段 | 意见必填、签名要求开关；常用语和签名录入由审批中心原型呈现 |
| 工作日时限与提醒 | 流程规则 → 时限与提醒 | 时限、到期前提醒输入，超时通知对象、每日汇总开关；工作日历在管理原型维护 |
| 委托、管理员干预、离职交接 | 审批中心个人设置 / 管理后台 | 非设计器交互，由对应模块提供；设计器说明无人和停用时的流程策略 |
| 使用范围、查看范围、保密、分级管理 | 流程规则 → 可见范围与接入授权 | 接入应用、发起部门 / 角色、查看权限、额外查看人、流程管理员可配置；不执行真实权限校验 |
| 操作留痕 | 本地版本历史；其他模块操作记录 | 版本发布追加记录；不模拟服务端防篡改校验链 |

超时自动同意和自动转交明确标注为二期，不提供初版执行入口。

## 第 5 节：审批数据与详情展示

| 设计项 | 页面 / 控件 | 精确交互范围 |
| --- | --- | --- |
| 字段定义 | 审批数据 | 可编辑 key、名称、九类字段类型、必传、摘要；可新增、删除 |
| 从示例提取 | 从 JSON 示例生成 | 解析对象，推断数字、明细数组或文本类型；追加新字段，同名保留 |
| 计算字段、明细 | 字段类型和“设置” | 可选择计算字段、明细表；可编辑表达式或明细列的文本配置；不执行表达式或生成多级结构编辑器 |
| 审批填写字段 | 字段设置 → 数据来源 | 可切换业务传入 / 审批填写；后一类在字段权限中增加“可填写” |
| 节点字段权限 | 选中节点 → 配置字段权限 | 业务数据只能只读 / 隐藏；审批填写字段可填写 / 只读 / 隐藏；按节点保存 |
| 发起校验、更新 | 审批数据底部 | 显示缺字段拒绝发起策略，可设置审批中更新策略及约定字段；不调用发起接口 |
| 审批编号 | 审批数据底部 | 编号规则文本可编辑保存 |
| 自动 / 自定义详情 | 详情排版 | 可选择模式、1～3 列、隐藏字段；拖动字段改变顺序；预览跟随顺序及可见性 |
| 业务原单嵌入 | 详情排版 → 嵌入业务原单 | 地址模板和打开方式可编辑；不实际访问或内嵌外部业务站点 |
| 人民币大写 | 详情排版 | 有显示配置入口；原型不实现人民币大写转换算法 |
| 摘要 | 审批数据的摘要复选框 | 字段级保存，并提示建议选择 3～5 个；不动态修改其他模块的静态样例摘要 |
| 附件与快照 | 附件字段、详情预览 | 展示虚构附件名称和只读快照；真实附件预览及上传交互由审批中心原型展示 |

自动和自定义排版共用原型中的简化网格；分组编辑、明细列宽拖动等复杂排版能力尚未在此原型实现。此处不生成业务表单，不允许修改业务系统传入的真实数据。

## 第 7 节：打印审批单

| 设计项 | 页面 / 控件 | 精确交互范围 |
| --- | --- | --- |
| 模板及基础配置 | 打印设置 | 模板模式、纸张、标题、单位、字体、意见签名范围、附票据页、水印均有配置入口并写入本地草稿 |
| 所见预览 | 右侧样张；打印预览 | 标题、单位、当前流程字段、可见顺序、节点意见来自当前草稿；以虚构数据绘制 |
| 打印 / 保存 PDF | 打印预览 → 浏览器打印 / 存为 PDF | 调用浏览器打印，仅打印审批单样张，隐藏应用导航与弹窗操作栏 |
| 字体与附件 | 配置说明 | 明确中文字体由单位上传、正式 PDF 由服务端生成；原型不下载字体，不合并附件 |

纸张选项、复杂模板布局、水印、签名图片和附件页在原型中属于可保存配置，尚未全部作用于浏览器样张；不可将浏览器样张视为正式 PDF 输出验收。

## 验证与边界

- JavaScript 通过 `node --check`；四模板 × 六页签通过无浏览器渲染检查；真实视觉和点击验收由主任务统一执行。
- 所有状态存于当前浏览器，无服务器持久化、真实鉴权、网络取人、外部动作或回调。
- 测试模式用于评审步骤状态，未实现票签计票、任意回路循环、并行令牌同步、完整条件表达式及中国式审批规则引擎。
- 已发布版本的历史列表与数量对比是本地演示记录，不具备生产环境的不可变存储或完整版本差异。
- 不新增外部依赖，不修改设计书、业务契约或产品源码。
