# T-004 审批操作全集与委托

状态：进行中
负责人：Codex 2026-10-20
里程碑：M2
依赖：T-003
设计书：§rules

## 目标

设计书第 4 节“审批人能做的”“发起人能做的”“管理员能做的”全部做成命令，加上委托代理、节点允许的操作、意见必填。

## 范围

可以新建、修改的文件：

- `backend/src/ApprovalService.Engine/Commands/`：同意、拒绝、退回（发起人 / 上一步 / 任一走过的节点；重新提交从头走或回到退回的节点；并行分支里的限制）、转交、加签（前 / 后 / 并）、减签、征询和回复、要求补充和补充、抄送、撤销同意、评论和 @、暂存意见、批量同意
- 发起人：撤回（可限制“第一个人处理前”）、催办（每小时一次）、重新提交、撤销申请
- 管理员：修改审批人、跳转、终止、离职交接、重发；都要填原因
- 委托代理：时间段、范围、不连环委托、代理人是发起人时的处理
- `backend/tests/ApprovalService.Backend.Checks/OperationChecks*.cs`（新建，按主题拆文件）

## 验收标准

- [ ] 每个操作都有“能做”和“不允许做”的场景（状态不对、不是当前审批人、节点不允许、超过频率）
- [ ] 每个操作产生事件，操作记录能还原“谁、代谁、什么时候、做了什么、意见”
- [ ] 退回的两种重新提交走法、并行分支里的退回限制都有场景
- [ ] 委托的四条规则都有场景
- [ ] `verify.ps1` 通过（见 AGENTS.md）
- [ ] 相关文档已更新（README、架构、契约、设计书受影响的部分）
