## 目标

流程复杂时用自由画布画：拖节点、随意连线、连线上写条件，能画回路；导入导出本系统的流程文件。

## 范围

可以新建、修改的文件：

- `frontend/src/designer/canvas/`（新建）
- 流程图库：候选 LogicFlow（Apache-2.0，选型时核对协议）；bpmn-js 要求保留 bpmn.io 标志，不用。新增依赖按 R8 写 ADR、征得同意再下载

## 共享文件

改这些文件前先在交接记录里写明改什么；改动尽量小，单独成一个提交：

- `frontend/package.json`、`frontend/package-lock.json`

## 验收标准

- [ ] 开始、结束、审批、办理、抄送、三种网关、子流程、自动节点都能拖进来、连线
- [ ] 连线上写条件；能画回路和跨分支跳转
- [ ] 和后端同样的发布校验，问题高亮到节点和连线
- [ ] 导出 BPMN 2.0 文件；只能导入本系统导出的，别的文件给出明确提示
- [ ] 缩放、平移、对齐吸附；风格和钉钉式一致
- [ ] `verify.ps1` 通过（见 AGENTS.md）
- [ ] 相关文档已更新（README、架构、契约、设计书受影响的部分）
