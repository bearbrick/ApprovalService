## 目标

## 范围

可以新建、修改的文件：

- `frontend/src/pages/mobile/`：底部四个标签（待办、已办、抄送、我的）、卡片列表、详情（操作按钮固定在底部）
- “设备能力”一层：拍照（上传前压缩）、手写签名、预览图片和 PDF，以后套壳时只换这一层
- 手机组件库候选 Vant（MIT），新增依赖按 R8 写 ADR、征得同意；也可以不用库
