# T-014 消息提醒、时限与工作日历

状态：待认领
负责人：—
里程碑：M3
依赖：T-005、T-007
设计书：§center、§rules

## 目标

邮件和站内消息提醒审批人和发起人；节点时限按工作日算，到期前、超时提醒；每天一封待办汇总；渠道做成扩展点，企业微信、钉钉只预留。

## 范围

可以新建、修改的文件：

- `Notifications` 模块：扩展点 `INotificationChannel`，邮件（SMTP）、站内消息两个实现；企业微信、钉钉只留接口
- 提醒规则：新待办、被催办、快到期、超时、审批结果、被抄送、被 @；个人订阅设置
- 工作日历（节假日、调休）和时限计算
- 邮件库如果要新增依赖，按 R8 处理

## 共享文件

改这些文件前先在交接记录里写明改什么；改动尽量小，单独成一个提交：

- 登记文件

## 验收标准

- [ ] 用假的 SMTP 服务检查邮件内容（摘要字段、打开链接，链接要登录）
- [ ] 时限跨周末、节假日、调休算对
- [ ] 每天早上的待办汇总可以关
- [ ] 提醒经待发队列发送，失败重试
- [ ] `verify.ps1` 通过（见 AGENTS.md）
- [ ] 相关文档已更新（README、架构、契约、设计书受影响的部分）

- 企业微信、钉钉的实现（预留）
