## 目标

把已有 Vue 骨架完善为可继续开发的公共框架，沿用标签服务与审批原型的风格；只做导航、布局、公共交互、请求处理与技术状态，不实现审批业务。

## 范围

- `frontend/src/**`、`frontend/public/**`、`frontend/tests/**`、`frontend/README.md`。
- 本任务文件、任务索引及架构文档的前端说明。
- 不添加或升级依赖，使用现有 Vue、TypeScript、Vite 和浏览器标准能力。

## 共享文件

- `frontend/src/App.vue`：组合桌面/手机外壳、页面及错误恢复边界。
- `frontend/src/model/routes.ts`：明确路由、导航与未知页面；保持 hash 地址。
- `docs/tasks/README.md`：只追加索引。
- `docs/architecture.md`：同步公共框架目录和责任。

## 验收标准

- [ ] 桌面/手机布局、主导航/子导航、标题/页签与原型风格一致，未知地址有返回入口。
- [ ] 路由直接打开、刷新、前进后退正常，切换页面恢复滚动与焦点。
- [ ] 请求统一处理 HTTP 错误、网络错误、超时、主动取消、无效 JSON；保留链路信息，不自动重试写请求。
- [ ] 服务连接状态支持加载、成功、失败、重试与卸载取消；界面有可恢复的错误边界。
- [ ] 公共图标、空状态、对话框和状态提示可复用，无演示业务数据或假登录。
- [ ] 新逻辑有场景检查，浏览器桌面/窄屏检查和全量 verify.ps1 通过。
- [ ] README、架构和交接记录同步，无新增依赖或契约变化。

## 不做

- 流程定义、引擎、审批操作、业务表单、组织/账号/权限实现、数据库实体与迁移。
- 真实登录或 API Key 管理；不以隐藏菜单冒充鉴权。
- 复制原型模拟数据、网络下载依赖、合并主分支或推送远程。
