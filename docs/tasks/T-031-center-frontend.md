# T-031 审批中心电脑前端基础

状态：进行中

里程碑：M3
依赖：T-025、T-008、T-009、T-010

## 目标

将已评审的审批中心桌面原型实现为正式 Vue 页面的展示与交互骨架，保留待接入的后端边界，不依赖尚未完成的组织身份与审批中心接口。

## 范围

- `frontend/src/pages/CenterPage.vue`、`frontend/src/pages/center/**`：四类列表、详情、筛选与操作展示、空状态和未接入提示。
- `frontend/src/model/center.ts`：纯逻辑筛选、排序、权限标记和状态模型。
- `frontend/src/api/center-adapter.ts`：审批中心页面所需的数据适配接口与明确的未接入实现，不写未定接口路径。
- `frontend/src/styles/center.css`：仅审批中心页面的样式。
- `frontend/tests/center-checks.ts`、`frontend/tests/checks.ts`：纯逻辑场景检查。
- `frontend/README.md`：页面范围、接入边界与验证说明。
- 本任务文件。

## 共享文件

- `frontend/src/App.vue`：仅为桌面审批中心选择正式页面，其他页面不改。
- `frontend/src/model/routes.ts`：若现有详情与列表路由不够，补充严格路由。
- `docs/tasks/README.md`：登记本独立前置任务。

## 验收标准

- [ ] 四类桌面审批列表及详情、筛选与搜索、加急和未读展示使用正式 Vue 组件，视觉对齐原型。
- [ ] 列表与详情有加载、空结果、错误和未接入状态；数据适配接口可替换为真实 API，但不伪造已连接状态。
- [ ] 操作栏只展示服务端声明可用的审批动作；没有可用动作时不允许假提交；审批中心不提供发起或编辑业务数据。
- [ ] 纯逻辑场景检查覆盖筛选、排序、批量选择约束和详情只读。
- [ ] `verify.ps1` 全量通过，相关文档与交接记录齐全。

## 不做

- 不新增 npm 依赖，不复制原型的浏览器本地模拟审批状态。
