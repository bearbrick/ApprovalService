## 目标

让正式流程设计器的多分支连线贴合节点端口、避开无关节点，条件文字可读；提供能直接看到现有画布内容的独立预览入口。

## 范围

- `frontend/src/designer/canvas/**`：节点锚点、连线路径与视觉反馈。
- `frontend/tests/canvas-checks.ts`：针对端口、避障与标签位置的场景检查。
- 本任务文件。

## 共享文件

- `docs/tasks/README.md`：登记任务，仅追加索引行。
- `frontend/tests/checks.ts`：如需登记新的场景检查，仅追加调用。
- `frontend/README.md`：同步正式画布预览入口与验证结果。

## 验收标准

- [ ] 开始/结束、网关、人工节点的连线端点贴合形状，多条边的端口清楚分开。
- [ ] 分支与汇合的线避开无关节点，条件标签不压节点。
- [ ] 正式费用报销画布在外置 Chrome 检查，并能直接从独立预览服务打开。
- [ ] 新几何行为有场景检查，`verify.ps1` 通过。
- [ ] 交接记录、文档和最终预览地址已更新。

## 不做

- 不伪造审批中心数据，也不绕过登录或业务接口。
- 不改流程定义契约或审批执行逻辑。
