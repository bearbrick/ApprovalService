## 验收标准

- [ ] 各完成分支的功能与任务文档均在整合分支且没有遗漏。
- [ ] 冲突已按契约优先和各任务交接记录处理，编译与场景检查通过。
- [ ] `verify.ps1` 全量通过，外置 Chrome 验证主要页面。
- [ ] 交接说明剩余未完成工作与主分支合并边界。

## 不做

- 不把整合分支直接合并到主分支或推送远程；该步骤按 AGENTS.md §6.2 征得用户确认。
- 不自行决定报表统计口径或新增不兼容契约。
