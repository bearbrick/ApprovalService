## 验收标准

- [x] 管理后台和审批中心本地登录刷新可恢复；退出后刷新不恢复。
- [x] 损坏、过期缓存安全清除；密码不保存；嵌入会话不写入或恢复本地登录缓存。
- [x] 并发续期只消费一次刷新令牌，退出后迟到响应不能复活会话。
- [x] 全量 `verify.ps1` 通过，外置 Chrome 验证登录与刷新。
- [x] 文档同步，预览静态文件更新。

## 不做
